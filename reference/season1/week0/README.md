# Week 0 source archive

74 original HEIC screenshots: 22 in the Utah game folder and 52 in the roster/preseason folder. Originals remain intact in the intake workspace's `season1/week 0/` folders. The manifest identifies every file and its SHA-256 checksum.

`ocr/` contains raw macOS Vision text recognition of all 74 screenshots. Character substitutions, table ordering and numeric errors are possible; verify against originals before using any value. Game, poll, Heisman and schedule values on the live site were checked visually.

`verified-game.json` records the 36–20 final, quarter scores, detailed offensive player statistics and scoring events. Use one passing touchdown plus one rushing touchdown for Dampier; the summary card's two touchdowns are total touchdowns. Do not label both as passing scores.

Sources: game screens IMG_4556–IMG_4573; schedules IMG_4574–IMG_4577; Media Top 25 IMG_4578–IMG_4580; Heisman IMG_4581; Utah depth chart IMG_4582–IMG_4604; BYU depth chart IMG_4605–IMG_4627; conference standings IMG_4628–IMG_4629.

Recovered JSON is historical reference only. Its rosters and preseason poll may disagree with the current dynasty screenshots. Source rosters are retained for research rather than exposed as a ratings dump.
